Edit a catalog item

Correct one item’s metadata, original text, or English translation. Save keeps a backup on this computer. Publish uploads only this item and waits for the website’s checks.

Use this editor for existing IDs. To delete an item, use “Delete an item from the catalog” at the end of this page. To add or rename a catalog item, use the full collection updater. The public website remains read-only.

Metadata

These are the source values, including source period labels and any HTML links. Preserve uncertainty in dates. The ID cannot be changed here.

Original text

Edit the source text, preserving paragraph breaks and any LaTeX markup. Publication still follows the Manuscripts / Publications availability rule.

English translation

Preserve paragraph breaks and any LaTeX markup. English edits also require checking the subject quotations and their paragraph references. If this text has reviewed quotations, publication stops until those references are reviewed against the correction.

Delete an item from the catalog

Removes the item whose ID is in “Exact catalog ID” from the website, together with every quotation taken from it in the subject compilations and every study-guide reading built on those quotations. The volume PDFs are not changed. Preview first; nothing changes until you confirm.

Progress

Keep the editor’s command window open until it finishes. The change goes to GitHub as a pull request; the website changes only after the pull request is merged there.
